A deterministic Node program that writes the funniest deadpan one-star
review of an everyday essential — sleep — to `/output/entry.txt`.

Entry: **"One star. Sleep promised me rest and delivered a dream about being late for work."** (81 characters, one line.)

Run it with:

```sh
node main.ts
```
